# My Website

A responsive personal website built with pure HTML, CSS, and JavaScript — no frameworks required.

## Features
- Sticky navbar with scroll-aware active-link highlighting
- Hero section with animated floating circles
- About, Skills, Projects, and Contact sections
- Scroll-reveal (fade-up) animations
- Mobile-responsive layout with a slide-in hamburger menu
- Contact form with client-side validation

## Getting Started

Open `index.html` in any modern browser — no build step needed.

## Tech Stack
HTML · CSS (custom properties, Grid, Flexbox) · Vanilla JavaScript
